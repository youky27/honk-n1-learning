# Honk on iStoreOS for N1

This repository is for learning, documenting, and collecting Honk build artifacts and configuration notes for the N1 device running iStoreOS.

## Status

Initial repository setup. No firmware images or installable packages have been published yet.

## Goals

- Document the N1 hardware and iStoreOS environment.
- Keep build instructions and source references reproducible.
- Publish device-compatible Honk packages only after build and compatibility checks.

## Safety

Do not install packages from this repository until their target architecture, dependencies, and checksums have been verified.
